# Master Farmer - Grindbot versioning

Copy-forward. Never rename or delete an old version folder.

## Identity

Canonical fields live in `version.lua`. `header.lua`, the GUI title, and the load log must match that table.

## On a material change

1. Bump `version.lua` and every `-- Version:` banner (never the `plugin_loader/` files - see below).
2. `python make_local.py` - syntax-checks every .lua, regenerates `manifest.lua`, and copies the plugin to `../Master_Farmer_Grindbot_vX.Y.Z/`. An existing version folder is never overwritten without `--force`.
3. Load that folder in Sylvanas in place of the loader plugin and test in game.
4. Commit as `vX.Y.Z: <summary>`, push `dev`, open a PR to `main`. Merging to `main` is what the game loads.
5. Do not bump for comment-only or rule-only edits.

**Never commit `plugin_loader.zip`.** It is marked `git update-index --skip-worktree` locally so it cannot be staged by accident.

**`plugin_loader/` stays unchanged across releases.** It is what users have installed; changing it forces a reinstall. If a change is ever required there, it is called out explicitly rather than folded into a release.

## Revert

Disable the newer plugin in Sylvanas and enable the older `Master_Farmer_Grindbot_vX.Y.Z` folder.
